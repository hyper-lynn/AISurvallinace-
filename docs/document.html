Executive Summary & System Architecture Overview

Shadow Eye (S-Eye) သည် Dynamic Camera Stream များမှ ရရှိလာသော Real-time Video Stream များကို Advanced Computer Vision နှင့် Deep Learning Algorithm များကို အသုံးပြု၍ လူအဝင်အထွက်၊ Face Detection, 2.5D Anti-Spoofing Liveness Verification, 512-D Deep Face Recognition, Human Pose Estimation နှင့် Human Fall Detection များကို တိကျစွာ ခွဲခြားစိတ်ဖြာပေးသော Tactical AI Surveillance Platform ဖြစ်ပါသည်။

စနစ်၏ ပန်းတိုင် (System Objective): ကျူးကျော်ဝင်ရောက်သူများ သို့မဟုတ် Target သတ်မှတ်ထားသော လူပုဂ္ဂိုလ်များကို RTSP/Dahua CCTV Video Channel များမှ Real-Time သိရှိဖော်ထုတ်ပေးပြီး၊ မတော်တဆ လဲကျခြင်း (Fall Event) ဖြစ်ပွားပါက Telegram Bot Alert Dispatcher မှတစ်ဆင့် Instant Photo Snapshot နှင့်တကွ Operatives / Tactical Fast Response Team များထံ စက္ကန့်ပိုင်းအတွင်း သတိပေးချက် အလိုအလျောက် ပေးပို့ပေးရန် ဖြစ်ပါသည်။

၂.၁ YOLOv8 Pose Detection & Strict Fall Angle Math Model

yolov8n-pose.pt နှင့် yolov8s-pose.pt Model များသည် လူတစ်ယောက်၏ ခန္ဓာကိုယ် Skeleton Keypoints (၁၇) ခု (မျက်လုံး၊ နား၊ ပခုံး၊ တံတောင်၊ လက်ကောက်ဝတ်၊ တင်ပါး၊ ဒူးခေါင်း၊ ခြေကျင်းဝတ်) ကို Real-time တိုင်းတာပေးပါသည်။

Fall Detection Vector Formula (လဲကျခြင်း တွက်ချက်မှု သင်္ချာညီမျှခြင်း):
လူတစ်ယောက်၏ ကျောရိုး (Spine Angle Vector) horizontal အပြင်အဆင်နှင့် လဲကျမှုကို တွက်ချက်ရန် ပခုံးလယ်မှတ် (Mid-Shoulder: S) နှင့် တင်ပါးလယ်မှတ် (Mid-Hip: H) တို့၏ Vector Delta ကို ယူပါသည်:
dx = MidHip_x - MidShoulder_x, dy = MidHip_y - MidShoulder_y
Spine Angle (θ) = | arctan2(dy, dx) * 180 / π |
Fall Trigger Condition: (θ < 30° OR dy < 15px) AND (Bounding Box Width > 1.25 * Height)

၂.၃ FAISS Vector Similarity & Metric Thresholds

ArcFace မှ ထုတ်ယူရရှိသော Feature Vector (u) နှင့် Target Database မှ Vector (v) တို့၏ Cosine Similarity ကို အောက်ပါအတိုင်း တွက်ချက်ပါသည်:

# Cosine Similarity Vector Matching Matrix def compute_cosine_similarity(embedding_u, embedding_v): norm_u = np.linalg.norm(embedding_u) norm_v = np.linalg.norm(embedding_v) sim = np.dot(embedding_u, embedding_v) / (norm_u * norm_v) return float(sim) # Threshold >= 0.40 to Trigger Verified Identity Match

၃.၃ AI Security Policy & Shield Guardrails

AI Protection Shield Protocols:
• Anti-Prompt Injection Filter: Gemini AI သို့ ဝင်လာသော Operator Prompt များတွင် Jailbreak Vectors (DAN, Prompt Override) ပါဝင်ပါက အလိုအလျောက် ပိတ်ဆို့ပါသည်။
• Credential Theft Prevention: System `.env` အတွင်းရှိ TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, Database Secret Passwords များကို Telegram Chat သို့ အပြင်ထွက်မသွားစေရန် Guardrail Shield မှ စစ်ဆေးဖြတ်တောက်ပါသည်။
• Privilege Access Control: Admin Privilege မရှိသော Telegram Chat Session များမှ Database Mutation မိန့်ခွန်းများ စေခိုင်းခြင်းကို ပယ်ဖျက်ပါသည်။
